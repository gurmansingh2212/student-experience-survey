# Student Experience Survey

A responsive and interactive web-based survey form designed to collect student feedback about their college experience.

## About the Project

The Student Experience Survey is a frontend web development project that allows students to share their opinions about college facilities, teaching quality, events, internships, and overall satisfaction.

The project focuses on creating a simple, user-friendly interface with form validation and interactive elements.

## Features

- Student name and email input
- Age validation
- Current role selection
- College satisfaction rating
- Multiple improvement area selection
- Additional comments section
- JavaScript form validation
- Submission confirmation message
- Simple and user-friendly interface

## Technologies Used

- HTML5 – Structure of the survey form
- CSS3 – Styling and layout
- JavaScript – Form validation and interactivity

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in the same folder.
4. Open `index.html`.
5. Run the project using the Live Server extension.
6. The survey form will open in your default browser.
